# 📚 AI Study Buddy

A chatbot that helps students study with AI, built with Python and Streamlit.

> 🚧 **Status:** In progress. The chat interface works, and the AI connection is being added.

## Features

- Clean chat interface built with Streamlit
- Remembers the conversation during a session
- Planned: connect to an LLM API for real answers
- Planned: simple explanations, quiz questions, and summaries

## Tech Stack

- Python
- Streamlit
- LLM API (to be added)

## How to Run Locally

    git clone https://github.com/Fridaynight10/ai-study-buddy.git
    cd ai-study-buddy
    pip install streamlit
    streamlit run app.py
